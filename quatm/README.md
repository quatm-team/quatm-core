# quatm package

This directory is the public AGPL-3.0 core of Quatm:

- `experiment/` — experiment lifecycle, parameters and scans
- `physics/` — atomic and ionic physics models
- `servers/` — properties, transport and data/image services
- `utils/` — shared utilities

The desktop GUI, web console, licensing layer, analysis tools, monitoring tools
and vendor driver catalogue are separate commercial components. They are not
part of this package.

See the repository [README](../README.md) and [LICENSE](../LICENSE).
