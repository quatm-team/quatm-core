# Code of conduct

Quatm is a scientific software community. Be respectful of differing
viewpoints, experimental constraints and institutional requirements. Give
technical criticism about code, data or design, not about the person. Do not
publish another laboratory's data, configuration or unreleased results.

Harassment, personal attacks, discriminatory language and deliberate
disruption are not acceptable. Report concerns to **contact@quatm.com**;
maintainers will review reports in good faith and take proportionate action.

This code is adapted from the Contributor Covenant, version 2.1:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
